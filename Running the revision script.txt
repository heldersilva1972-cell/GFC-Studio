📱 Mobile App Locations
When you run the script for the mobile project, it targets files inside the apps/GFC-Mobile-Standalone and apps/webapp directories:

Version Authority: apps/GFC-Mobile-Standalone/version.json

Development Service Worker: apps/GFC-Mobile-Standalone/GFC.Mobile/wwwroot/service-worker.js

Published Service Worker: apps/GFC-Mobile-Standalone/GFC.Mobile/wwwroot/service-worker.published.js

Blazor Index File: apps/GFC-Mobile-Standalone/GFC.Mobile/wwwroot/index.html

Client Settings: apps/GFC-Mobile-Standalone/GFC.Mobile/wwwroot/appsettings.json

Server App Settings: apps/webapp/GFC.BlazorServer/appsettings.json


RUNNING THE SCRIPT FOR MOBILE
.\sync-version.ps1 -Next


🖥️ POS App Locations
When you switch the script to -Project "POS", it completely shifts gears and looks inside the apps/GFC-Pos-Standalone folder structure instead:

Version Authority: apps/GFC-Pos-Standalone/PosVersion.props

C# Version Service: apps/GFC-Pos-Standalone/GFC.Pos.UI/Services/PosVersionService.cs

Mobile Project Config: apps/GFC-Pos-Standalone/GFC.Pos.Mobile/GFC.Pos.Mobile.csproj

Text Version Reference (Terminal): apps/GFC-Pos-Standalone/GFC.Pos.Terminal/wwwroot/version.txt

Text Version Reference (UI): apps/GFC-Pos-Standalone/GFC.Pos.UI/wwwroot/version.txt

Blazor Index Files: * apps/GFC-Pos-Standalone/GFC.Pos.Terminal/wwwroot/index.html

apps/GFC-Pos-Standalone/GFC.Pos.UI/wwwroot/index.html

Service Workers: * apps/GFC-Pos-Standalone/GFC.Pos.UI/wwwroot/service-worker.js

apps/GFC-Pos-Standalone/GFC.Pos.UI/wwwroot/service-worker.published.js

apps/GFC-Pos-Standalone/GFC.Pos.Terminal/wwwroot/service-worker.js

apps/GFC-Pos-Standalone/GFC.Pos.Terminal/wwwroot/service-worker.published.js

Shared Server App Settings: apps/webapp/GFC.BlazorServer/appsettings.json (Updates the PosRevision block here).

RUNNING THE SCRIPT FOR POS
.\sync-version.ps1 -Project "POS" -Next




Because it relies on $PSScriptRoot, as long as your PowerShell window is pointed to the directory containing this script, it will dynamically build these paths correctly on your machine.

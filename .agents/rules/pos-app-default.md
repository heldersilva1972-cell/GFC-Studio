# DEFAULT POS APP TARGET RULE

* **STRICT POS APP TARGET:** Whenever the user mentions "POS app", "POS", "terminal", or "the app", target ONLY the **POS Standalone App** (`apps/GFC-Pos-Standalone/GFC.Pos.UI/Pages/PosTerminal.razor`).
* **NO WEB APP SIMULATOR EDITS:** Do NOT make any changes to the POS simulator on the web app (`GFC.BlazorServer`) UNLESS the user explicitly asks to make changes to the web app POS simulator.
